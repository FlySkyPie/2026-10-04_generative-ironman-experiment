# Generative Code Contribution Policy

1. The key words "MUST", "MUST NOT", "REQUIRED", "SHALL", "SHALL NOT", "SHOULD", "SHOULD NOT", "RECOMMENDED", "MAY", and "OPTIONAL" in this document are to be interpreted as described in RFC 2119.
2. Content generated by an LLM MUST be recorded using Git commits.
    1. The format of the Git commit record MUST comply with `{Tool Name} {Tool Version} <{Model}@{Model Provider}>`, for example:

        ```shell
        git commit -m "feat: implement inferences" \
        --author="Kilo Code v4.153.0 <minimax+minimax-m2.5@openrouter.ai>"
        ```

    2. "generated by an LLM" including but not only:
        - ReAct/Agentic workflow.
        - Chatbot generated code.

3. RECOMMENDED separate Generative Code and human modification into different commits.
